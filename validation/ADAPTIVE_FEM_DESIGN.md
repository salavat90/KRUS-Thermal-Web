# KRUS-Thermal: адаптивная FEM-сетка (проект алгоритма)

## Область применения
Отдельное FEM-ядро. Основной `index.html` не изменять до прохождения тестов.

## Геометрия
1. CAD-контуры трубы, продукта, изоляции и каждого кабеля. Кабель — отдельная замкнутая область, а не источник в соседних элементах.
2. Общие узлы на идеальных контактах; интерфейсные элементы при конечном контактном сопротивлении.
3. Начальная фоновая квадратная сетка — только для оценки температурного поля и целевого размера элементов, **не** смешивать произвольные квадраты с несогласованными треугольниками.
4. Конечная расчётная сетка — конформная неструктурированная треугольная (P1), с обязательными узлами на всех материальных границах.

## Целевая функция размера h(x)
- Геометрический ограничитель: кабель 6–10 элементов по диаметру как стартовое требование, стенка трубы >= 3 элемента по толщине; подтвердить сеточной сходимостью.
- Радиальные зоны вокруг каждого кабеля с плавным ростом размера (ограничение отношения соседних размеров, например <= 1.4).
- Сгущение на материальных границах и у контактов.
- После грубого расчёта вычислять индикатор ошибки по восстановленному градиенту и скачку нормального потока на межэлементных гранях. Один лишь |grad T| не является строгим оценивателем погрешности.
- Маркировать верхнюю долю вклада в оценку ошибки, перестраивать сетку и решать заново.
- Защита от вырожденных треугольников: минимальный угол, положительная площадь, отсутствие перекрытий/зазоров, корректные граничные метки.

## FEM
- Уравнение: div(lambda grad T) + q_v = 0.
- Для каждого кабеля: интеграл q_v dA = P_cable [Вт/м] в 2D сечении единичной длины.
- Внутренний продукт: либо сопряжённая теплопроводность без движения (closed), либо заданная температура/Robin с документированным источником тепла (fixed).
- Наружная конвекция: Robin, h [Вт/(м² К)], T_inf.
- Контроль: Q_cables + Q_product - Q_ambient = 0 [Вт/м]; отдельно резидуал линейной системы.
- Извлекать T_max кабеля только на узлах/элементах области кабеля, а не глобальный максимум.
- При фиксированном T продукта включать его тепловой поток в баланс со знаком.

## Алгоритм адаптации
1. Построить грубую конформную сетку с геометрическими ограничителями.
2. Решить FEM, проверить невязку линейной системы и баланс энергии.
3. Вычислить индикатор локальной ошибки, маркировать элементы.
4. Локально сгущать с соблюдением конформности и качества.
5. Повторять до стабилизации q_ambient, T_water и T_cable_max на последовательных сетках.
6. Отчёт: узлы, элементы, минимальный угол, итерации, q, T, баланс, ошибка между сетками и время.
7. Ограничения на время/число элементов, при превышении — явный статус «не сошлось», без инженерного заключения.

## Тесты до публикации
- Аналитическая однородная пластина.
- Аналитический цилиндр без кабеля.
- Два кабеля: сумма интегралов источников равна заданной мощности.
- Сравнение грубой/адаптивной/тонкой сетки при одинаковых материалах и границах.
- Проверка температуры кабеля на независимом локальном сгущении.
- C001 ELCUT только после восстановления точной геометрии и граничных условий.

## Статус
Это спецификация реализации, не готовый генератор адаптивной сетки. Существующая FEM Beta пока не удовлетворяет требованиям к отдельным геометрическим областям кабелей.
