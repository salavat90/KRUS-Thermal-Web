# План валидации КРУС-Thermal 2D

## Этап A — аналитическая цилиндрическая задача
- Труба: наружный диаметр 273 мм, стенка 8 мм, изоляция 45 мм.
- Внутренняя область поддерживается при +5 °C, наружный воздух −45 °C.
- λ стали 45 Вт/(м·К), λ изоляции 0,04 Вт/(м·К), h снаружи 12 Вт/(м²·К).
- Мощность нагревателей 0 Вт/м; их теплопроводность приравнена к изоляции.
- Сравнить численные потери КРУС и аналитические потери через концентрические цилиндры.
- Проверить знак потока и баланс Q_от_воды = Q_наружу.
- Предварительный порог smoke-теста: 15%; целевая точность для инженерной версии пока не утверждена.
- **Не интерпретировать прохождение smoke-теста как валидацию продукта.**

Аналитическая формула на 1 м длины:

```
R = ln(r_out_pipe / r_inner_pipe)/(2*pi*lambda_steel)
  + ln(r_out_ins / r_out_pipe)/(2*pi*lambda_ins)
  + 1/(h*2*pi*r_out_ins)
q = (T_water - T_air)/R
```

## Этап B — сходимость сетки
Требуется отделить расчётное ядро от интерфейса, добавить независимый параметр N, запустить минимум три сетки, измерить изменение q и температур оболочек. Сглаживание изображения не заменяет уточнение сетки.

## Этап C — сопоставление с ELCUT
Для всех 15 случаев в `validation/elcut-reference.json` нужны фактические геометрические и физические параметры исходных моделей. В частности, номинальный диаметр нельзя автоматически принимать за наружный; также неизвестны толщина стенки, диаметр кабеля, контакт, точная раскладка и назначения граничных условий.

Пока эти параметры не подтверждены, автоматическое сравнение с ELCUT **не запускается** и статус каждого случая — «не проверено».

## Этап D — критерии выпуска
- Успешные тесты CI и измеренное время расчёта.
- Сеточная сходимость для теплопотерь и максимальной температуры кабеля.
- Энергетическая невязка в Вт/м и относительных процентах.
- Независимые контрольные расчёты, включая случаи без кабеля.
- Документированные допущения: отсутствие естественной конвекции воды, идеальные контакты, постоянные λ.
