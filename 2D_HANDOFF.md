# KRUS-Thermal 2D — инструкция для нового чата и сопровождения

## Быстрый старт
Проект: https://github.com/salavat90/KRUS-Thermal-Web
Основной экспериментальный 2D FEM: `random-mesh.html`
Адрес: https://salavat90.github.io/KRUS-Thermal-Web/random-mesh.html
Отдельная 3D разработка: `3d/fem-lab.html`. Не переносить 3D изменения в 2D без прямого запроса.
Общий исторический журнал: `PROJECT_HANDOFF.md`.

## Цель
Тепловой FEM поперечного сечения трубы с металлом, жидкостью, предизоляцией, основной изоляцией и нагревательными кабелями. Не подгонять результаты под ELCUT. Сопоставлять одинаковые физические условия, включая граничные условия и материалы.

## Что есть
- Адаптивные случайные вершины и триангуляция с повышенной плотностью у кабелей и материальных границ.
- Отдельные параметры геометрии, количества вершин, зерна, мощностей кабелей, λ и конвекции.
- Два режима воды: стационарное равновесие и поддерживаемая температура.
- FEM решатель в браузере через Web Worker.
- Визуализация точек, треугольников, температур, зум/пан, измерение ближайшего узла.
- Вывод энергетического баланса и явная пометка предварительности из-за неконформных границ.
- 2026-11-06: добавлены «Контрастная/Классическая» палитры, усиление цветового контраста, диапазон «полный» либо «2–98% узлов», легенда из той же функции, что и окраска. Сетка/точки по умолчанию скрыты. Эти параметры НЕ меняют расчёт, только отображение.

## Обязательные правила сопровождения
1. Перед правками читать `random-mesh.html`, актуальные тесты и этот документ.
2. Не заменять рабочий 2D FEM новым отдельным прототипом. Изменения делать в существующем файле, минимальным патчем.
3. Не менять физику, граничные условия и мощность ради визуального сходства с ELCUT.
4. Не заявлять о точности или валидации без тестов. В частности, материальные границы пока неконформны.
5. Любая новая палитра должна сохранять однозначную температурную легенду. При отсечении крайних 2% явно предупреждать, что цвета насыщаются на концах шкалы.
6. Для каждого изменения: проверка JS синтаксиса, тест расчёта и энергетического баланса, проверка браузерной отрисовки (если доступна), затем коммит и обновление этого документа.
7. Не путать теплопотери (Вт/м) с мощностью нагревателя (Вт/м), температуру с плотностью теплового потока (Вт/м²).
8. Замороженные исторические 2D варианты не изменять без прямого указания. 3D и серверный установщик не трогать при работах по 2D.

## Следующие проверки
- Визуально сравнить контрастную и классическую палитры на одинаковом сохранённом FEM решении.
- Убедиться, что 2–98% режим корректно отражает насыщение экстремальных температур, не подменяя численные результаты.
- Проверить, что легенда соответствует используемой палитре при изменении параметров.
- Проверить физическую корректность и сходимость 2D FEM независимо от цветовой шкалы.
- Рассмотреть отдельную настройку диапазона цветов вручную (минимум/максимум), без изменения решателя.

## Как продолжить в новом чате
«Открой GitHub salavat90/KRUS-Thermal-Web, прочитай `2D_HANDOFF.md`, `PROJECT_HANDOFF.md` и `random-mesh.html`. Продолжай доработку существующего 2D FEM, не затрагивая 3D и сервер. После каждого изменения запускай доступные тесты и обновляй `2D_HANDOFF.md`.»
